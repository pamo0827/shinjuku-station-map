# 新宿駅 構内図

新宿駅の構内図（地下7階〜4階、立体図、経路の案内図）を、GitHub Pages で公開するためのリポジトリです。

- ページ: `site/`（静的な HTML。`main` に push すると GitHub Actions で公開されます）
- 公開先: https://pamo0827.github.io/shinjuku-station-map/

## データの出典

- 「新宿駅周辺屋内地図オープンデータ」（国土交通省）を加工して作成 — https://www.geospatial.jp/ckan/dataset/mlit-indoor-shinjuku-r2
- 道路・お店の位置: © OpenStreetMap contributors（ODbL） — https://www.openstreetmap.org/copyright
- 設備の位置は、各社の駅構内図を参考にした、おおよその位置です。改札の中（斜線）とホームは推定を含みます。
